# Pratiksha Growth Media Website

A responsive static website built with plain HTML, CSS and JavaScript. No framework, build step, database, or paid AI subscription is required.

## Files
- `index.html` — complete website (styles and scripts included)
- `assets/pgm-mark.png` — cropped official PGM mark from your saved brand artwork

## Before publishing
1. Review the business phone, email, location and service prices in `index.html`.
2. The PGM logo mark from your saved brand artwork is already included.
3. Test the WhatsApp enquiry form and navigation on mobile.

## Publish on Hostinger
1. In Hostinger hPanel, open Websites / Hosting and choose the domain `pratikshagrowthmedia.in`.
2. Open File Manager, then `public_html`.
3. Upload `index.html` (or upload the ZIP and extract it) directly inside `public_html`.
4. Ensure the file path is `public_html/index.html`, not `public_html/pratiksha-growth-media/index.html`.
5. Enable/verify SSL in hPanel. Visit `https://pratikshagrowthmedia.in`.

Note: This package does not include hosting or domain registration. Since the domain is already registered at Hostinger, a hosting plan is still needed if publishing on Hostinger. A free static host can also be used if preferred.
